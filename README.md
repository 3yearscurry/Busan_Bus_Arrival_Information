# 부산(김해) 버스 도착 정보 시스템 Mac 지원 종료 안내

안녕하세요. **부산(김해) 버스 도착 정보 시스템**입니다.

항상 저희 서비스를 이용해 주시는 이용자 여러분께 진심으로 감사드립니다.

**부산(김해) 버스 도착 정보 시스템**은 지속적이고 안정적인 서비스 제공을 위해 다방면으로 검토를 진행해 왔으나, 급변하는 OS 환경 및 기술적 유지보수의 한계로 인해 부득이하게 **2026년 11월 1일부**로 **Mac(macOS) 환경에 대한 지원을 종료**하게 되었습니다.

지속적인 업데이트와 안정적인 서비스 품질 유지가 어려운 상황에서 내린 불가피한 결정인 만큼, Mac 이용자 여러분의 너른 양해를 부탁드립니다.

지원 종료 일시: **2026년 11월 1일(일) 09:00**

지원 종료 대상: **Mac(macOS) 버전 서비스 전반**

종료 내용: **Mac 환경 내 서비스 업데이트, 기능 개선, 오류 수정 등 기술 지원 중단**

지원 종료 이후에는 Mac 환경에서의 접속이나 기능 작동이 원활하지 않을 수 있으니 이용에 참고해 주시기 바랍니다.

그동안 Mac 환경에서 서비스를 이용해 주신 분들께 깊은 감사의 말씀을 드리며, 서비스 이용에 불편을 끼쳐 드리게 된 점 고개 숙여 사과드립니다. 
보다 안정적이고 신뢰할 수 있는 대중교통 정보 서비스를 제공하기 위해 최선을 다하겠습니다.

감사합니다.

# 부산(김해) 버스 도착 정보 시스템

[![API 서버 상태](https://img.shields.io/endpoint?url=https://gist.githubusercontent.com/3yearscurry/d179f0445e5df8a51b85c45c5caeda35/raw/server-status.json)](https://github.com/3yearscurry/Busan_Bus_Arrival_Information/releases)

부산광역시(김해시) 버스 도착 정보를 실시간으로 조회하는 데스크톱 앱입니다.

`본 프로그램은 부산광역시(김해시)가 제작·운영·후원하는 공식 프로그램이 아닙니다.`

## 권장 사양

* **운영체제(64비트 전용)**:
  * **최소**: `Windows 10 21H2(19044) 이상`
  * **권장**: `Windows 11 22H2(22621) 이상`

- **CPU** : `Intel Core i3 8세대 / AMD Ryzen 3 이상`

* **RAM**:
  * **최소**: `8 GB (DDR3 이상)`
  * **권장**: `16 GB 이상 (DDR4 이상)`

* **GPU**:
  * **최소**: `DirectX 11 지원 그래픽 (Intel HD Graphics 4000 이상)`
  * **권장**: `DirectX 12 지원 그래픽`
    * 내장: `Intel UHD Graphics 620/630 또는 AMD Radeon Vega 시리즈 이상`
    * 외장: `NVIDIA GeForce GT 1030 / GTX 1050 또는 AMD Radeon RX 550 이상`

- 네트워크 : `100 Mbps 초고속 인터넷 이상`

## Mac에서 "'BusanBus'은(는) 손상되었기 때문에 열 수 없습니다" 오류 발생 시
터미널에서 xattr -cr /Applications/BusanBus.app 실행 후 프로그램 재실행
