# 지원 종료 안내

안녕하세요.

그동안 프로그램을 이용해 주신 모든 분들께 진심으로 감사드립니다.

여러 가지를 고민한 끝에, 현재 제공 중인 프로그램의 개발 및 지원을 종료하기로 결정했습니다.

최근에는 프로그램의 실용성이 많이 낮아졌다고 판단했고, 앞으로도 지속적인 업데이트와 유지보수를 이어가기 어렵다고 판단하여 지원 종료를 결정하게 되었습니다.

이에 따라 앞으로는 새로운 기능 추가, 버그 수정, 기술 지원 및 업데이트가 더 이상 제공되지 않습니다.

부족한 프로그램이었지만 사용해 주시고 관심 가져주신 모든 분들께 다시 한번 감사드립니다.

감사합니다.

서비스는 `2026년 8월 1일`까지 이용하실 수 있습니다.

# 부산 버스 도착 정보 시스템

[![API 서버 상태](https://img.shields.io/endpoint?url=https://gist.githubusercontent.com/3yearscurry/d179f0445e5df8a51b85c45c5caeda35/raw/server-status.json)](https://github.com/3yearscurry/Busan_Bus_Arrival_Information/releases)

부산광역시 버스 도착 정보를 실시간으로 조회하는 데스크톱 앱입니다.

## 요구 사항
최소 : Windows 8.1

권장 : 
- Windows : Windows 10 21H2 이상 또는 Windows 11

- Mac : macOS 14 Sonoma 이상

## Mac에서 "'BusanBus'은(는) 손상되었기 때문에 열 수 없습니다" 해결 방법
터미널에서 xattr -cr /Applications/BusanBus.app 하고 재실행

[최신 릴리즈](https://github.com/3yearscurry/Busan_Bus_Arrival_Information/releases/latest)에서 설치 파일을 받을 수 있습니다.
